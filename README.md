# Resume Website

My web-based resume for Web Development (BSIT, Polytechnic University of the Philippines). Built with HTML, CSS and JavaScript only.

## View it

- Live: coming soon
- Locally: open `index.html` in a browser, or run `python -m http.server` in this folder and go to http://localhost:8000

## Files

- `index.html`: page content
- `css/style.css`: styles
- `js/script.js`: interactive parts
- `images/`: photo, screenshots and icons
